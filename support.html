Help and support

ClipAI_Word 1.2 · Updated October 29, 2026

ClipAI_Word proofreads and rewrites the text you select in Microsoft Word, using the AI provider you choose: OpenAI, Claude (Anthropic), Gemini (Google), or Grok (xAI). It changes only the words that need changing, so formatting, footnotes, fields, and pictures stay in place.

What you need

  • Word for Microsoft 365, Word 2021 or later on Windows or Mac, or Word on the web.
  • An internet connection.
  • An API key from one of the providers. The provider bills its usage to your account, so check its prices and set a spending limit.

Install

Windows

  1. Download the Windows installer (install-windows.cmd) and open it. If Windows SmartScreen warns you, select More info › Run anyway. No administrator rights are needed.
  2. Restart Word. Select ClipAI on the Home tab. If you don’t see it, select Home › Add-ins and choose ClipAI_Word.

Mac

  1. Save the add-in manifest (manifest.xml).
  2. In Finder, select Go › Go to Folder, enter ~/Library/Containers/com.microsoft.Word/Data/Documents/wef (create the wef folder if it doesn’t exist), and copy manifest.xml into it.
  3. Restart Word, then select Home › Add-ins and choose ClipAI_Word.

Word on the web

  1. Save the add-in manifest (manifest.xml).
  2. Select Home › Add-ins › More Add-ins, then My Add-ins › Upload My Add-in, and choose the file. Your organization may turn this option off.

Get started

  1. Select ClipAI on the Home tab. The first time, read the notice about AI and your data, then select Continue.
  2. In Settings, choose a provider and paste your API key. Create a key here: OpenAI, Claude, Gemini, Grok.
  3. Select Save. ClipAI_Word checks the key and loads the models it can use.
  4. Optionally choose the model and reasoning effort. Higher effort gives more careful results but is slower and costs more.

You can save keys for several providers and switch between them with the AI provider list above the commands.

Use it

Proofread

Select text in your document and choose Proofread selection. Grammar, spelling, and punctuation are corrected; meaning and style stay the same.

Rewrite

On the Rewrite tab, describe what you want, or pick a style or translation, then choose Apply instructions (or press Ctrl+Enter, ⌘Enter on Mac).

Review and undo

The changes are made by AI and can be wrong. Read them before you share the document. To undo, press Ctrl+Z (⌘Z on Mac). While a request is running, you can select Cancel; the document is not changed.

What is protected

  • Changes that would overwrite pictures, content controls, fields, footnotes, or endnotes are skipped, and ClipAI_Word tells you how many were skipped.
  • When a rewrite changes the number of paragraphs, the selection must not contain tables or any of the items above.
  • You can process up to 4,000 words at a time.

Troubleshooting

Message or problem What to do
The API key isn’t valid Copy the key again from your provider account, select Change, and paste it. Check that the key belongs to the provider selected in Settings.
No credit left or spending limit reached Add credit or raise the limit in your provider account’s billing settings.
Too many requests Wait a minute and try again, or choose a smaller model.
The model isn’t available or can’t be used Choose another model in Settings. ClipAI_Word needs models that support structured (JSON) responses.
Couldn’t connect or the request timed out Check your connection. On company networks, the firewall must allow api.openai.com, api.anthropic.com, generativelanguage.googleapis.com, or api.x.ai.
The selected text changed while processing Don’t edit the selection until the command finishes, then run it again.
The response was cut off, or the selection is too long Select fewer paragraphs and run the command in parts.
The ClipAI button is missing Restart Word. If it’s still missing, install the add-in again.

Privacy and security

Selected text goes directly from your device to the provider you chose, only when you run a command. API keys stay on your device. ClipAI_Word has no server and collects no data. Read the privacy policy and the terms of use.

Report a problem or inappropriate content

If ClipAI_Word produced harmful, offensive, or inappropriate text, or something doesn’t work, open an issue on GitHub. Describe what you did and which provider and model you used, but don’t include API keys or confidential document content. We review every report.

Uninstall

  • Windows: run the uninstaller (uninstall-windows.cmd), then restart Word.
  • Mac: delete manifest.xml from the wef folder above, then restart Word.
  • Word on the web: select Home › Add-ins › More Add-ins › My Add-ins, open the menu for ClipAI_Word, and select Remove.
